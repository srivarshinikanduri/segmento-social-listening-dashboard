# Segmento Social Listening Dashboard

A sample Social Listening Dashboard developed as part of the Segmento task.

The application provides a simple dashboard interface to monitor and understand social media data such as mentions, engagement, sentiment, trends, and platform-wise activity.

## 🎯 Project Objective

The main objective of this project is to create a sample web application for a Social Listening platform.

The dashboard is designed to provide a clear view of social media insights and can be extended later with real APIs, web scraping, RSS feeds, and other data sources.

## 🚀 Features

- Social media dashboard
- Platform-wise data visualization
- Social media mentions
- Engagement metrics
- Sentiment analysis overview
- Trending topics
- Charts and analytics
- Clean and responsive user interface
- Sample/mock data for demonstration

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Recharts
- Git & GitHub

## 📊 Dashboard Overview

The dashboard is designed to display:

- Total Mentions
- Engagement
- Sentiment
- Trending Topics
- Platform Performance
- Social Media Activity
- Data Visualization

Currently, the application uses sample data to demonstrate the dashboard functionality.
